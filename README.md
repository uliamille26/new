# Список дел

Простое веб-приложение для списка задач. Один файл `index.html`, без установки и зависимостей.

## Возможности

- Добавить задачу
- Отметить выполненной
- Удалить задачу
- Фильтр: все / активные / готовые
- Задачи сохраняются в браузере и не пропадают после перезагрузки страницы

## Как запустить

Скачайте `index.html` и откройте его в любом браузере.
